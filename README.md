# PIC16F877A LCD Interfacing

A basic embedded systems project demonstrating how to interface a 16x2 LCD with the PIC16F877A microcontroller.

## 🚀 Project Overview

This project displays text on a 16x2 LCD using the PIC16F877A microcontroller.

The LCD is operated in 4-bit mode and programmed using Embedded C.

## 🛠️ Tools Used

- PIC16F877A
- MPLAB X IDE
- XC8 Compiler
- Proteus
- Embedded C
- 16x2 LCD

## 🔌 LCD Connections

| LCD Pin | PIC16F877A Pin |
|---------|----------------|
| RS | RD0 |
| EN | RD1 |
| D4 | RD4 |
| D5 | RD5 |
| D6 | RD6 |
| D7 | RD7 |
